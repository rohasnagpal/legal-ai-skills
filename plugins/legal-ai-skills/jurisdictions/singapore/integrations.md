# Singapore integrations and registries

Singapore is included in the same plugin and uses the host's authorised official-website research and supplied documents. No Singapore-specific MCP/API connector is added by this module. The advertised 14 connected research sources remain unchanged; Singapore websites are not counted as connected simply because their URLs appear here.

- Use SSO, SG Courts Judgments and the responsible regulator through tools actually available in the host, following [authoritative sources](authoritative-sources.md). Disclose blocks, coverage and unavailable text.
- For ACRA/Bizfile, land/title, IP, licence or court records, check whether authorised access, login, payment or a user-supplied extract is needed. Do not infer an official Singapore entity record from GLEIF or a similarly named overseas company. Match the UEN and document date; search absence is not clearance.
- Public judgments are distinct from private court files and electronic filing. Never claim eLitigation filing access from public judgment access.
- Existing local calculators support supplied-rule arithmetic; local law, holidays and cutoffs need verification. Existing document tools support actual installed local engines. Existing sanctions screening covers its stated US/UK/UN lists; it is not a complete Singapore compliance check.
- Preserve query, source, identifiers, version, retrieval time and result status. Do not store credentials, bypass controls, acquire paid records or send confidential documents without authorisation.

If tools are unavailable, work from authorised supplied text within its temporal scope, request missing primary sources and mark checks outstanding. Follow the central [legal-research protocol](../../integrations/legal-research.md) and [matter continuity](../../assets/firm/matter-continuity.md).
