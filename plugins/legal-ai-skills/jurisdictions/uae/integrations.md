# UAE integrations

Use the host's authorised website research and supplied records. This module adds instructions and local skills, not a dedicated UAE MCP connector, private docket access, paid registry entitlement or automatic filing capability.

Retrieve official sources from the [source guide](authoritative-sources.md). Confirm entity identifiers, record type, source date, authorised access and fees before registry searches. Record actual queries and results; absence of a result does not establish clearance. Obtain authorisation for purchases or confidential external uploads. Never store credentials in matter logs.

Use available calculators only after verifying local legal premises. Use document tools only for their supported formats and operations. On access failure identify the affected proposition, request authorised text or qualified local verification and continue only within the available evidence.
