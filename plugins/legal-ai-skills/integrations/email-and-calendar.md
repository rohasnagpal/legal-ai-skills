# Email and calendar

## Required capability

Support authorised retrieval of matter correspondence and deadlines through any available provider, including Gmail or Microsoft 365, without requiring either.

## Expected actions

- search messages by scoped custodians, participants, terms and dates;
- retrieve a message with headers, thread context and attachments where permitted;
- search calendar entries and obtain relevant date, participant and location metadata;
- draft, but not send, a message unless the user expressly requests sending and the tool supports it;
- create or update a calendar item only on express instruction.

## Legal uses

- locate transaction instructions, agreed positions and notices;
- identify filing, renewal, hearing, closing and response dates;
- collect authorised correspondence for disputes or investigations;
- prepare response drafts and meeting materials.

## Safeguards

Confirm the account, custodians, date range, search terms and intended use before retrieval. Respect privilege, confidentiality, personal-data minimisation and investigation scope. Preserve message identifiers and header metadata when provenance matters. Do not treat a missing search result as proof that no communication exists.

Sending messages, inviting attendees or altering calendars changes external state. Obtain an explicit user request for the specific action and present the intended recipients and content before execution where the host requires confirmation.

## Fallback

Request an authorised email export, message files, correspondence bundle or calendar extract. Continue from the supplied material and mark unsearched accounts, custodians or periods as limitations.
